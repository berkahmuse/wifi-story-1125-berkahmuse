Entry for the [make.fun bounty "Tell a Whole Story in 32 Characters"](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978): one Wi-Fi network name of at most 32 characters that lands a joke and implies a story in the few words a passer-by sees in a phone's network list.

## The Wi-Fi name

> MyKidSoldThePasswordAtSchool

28 characters. The family Wi-Fi password is no longer a secret — the kid sold it at school. Six words imply a whole story: who (my kid), what happened (sold the password), and where (at school). Behind the parents' backs a little schoolyard black market is running, and every neighbour's phone now knows it.

## Run it

```sh
node main.ts
# writes /output/entry.txt
```

`main.ts` writes the single name to `/output/entry.txt`, deterministically — every run produces byte-identical output.
